# License Text Copies

This directory contains some commonly used licenses, for convenience of copying the license file to a new project. Other licenses can be found at <https://spdx.org/licenses/> and <https://github.com/spdx/license-list-data/tree/main/text>.

Each license's file name is its SPDX license identifier.

Note that the following licenses require filling additional information:

- [BSD 3-Clause "New" or "Revised" License](./BSD-3-Clause.txt)
- [MIT License](./MIT.txt)
